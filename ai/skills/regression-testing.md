# Skill: Regression Testing

---

## 1. Workflow Instructions

To prevent regressions:

- **Step 1: Run full test suite**: Run the whole test command before submitting any pull request.
- **Step 2: Compare outputs**: Verify if output matches baseline values.
- **Step 3: Edge cases**: Write tests targeting null inputs, empty lists, boundary values, and malformed parameters.
- **Step 4: Dependency check**: Ensure imports are clean and don't introduce circular logic.

---

## 2. Testing Framework Configuration
- **Backend Test Runner**: `uv run pytest`
- **Backend Lint Gate**: `uv run ruff check .`
- **Frontend Unit Test Runner**: `cd frontend && npm run test`
- **Frontend Route/E2E Gate**: `cd frontend && npm run test:e2e`
- **Coverage Tool**: Not configured yet; use targeted backend/frontend tests plus E2E route-health coverage.
