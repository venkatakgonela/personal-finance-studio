# Skill: Database Migration

---

## 1. Migration Steps

When changing database schemas:

- **Step 1: Backup & Sandbox**: Create migration files and test them on an isolated local database first.
- **Step 2: Generate Migration**: Run the migration generation script.
- **Step 3: Review Auto-generated Code**: Double-check SQL commands to avoid locks, column deletes, or index crashes.
- **Step 4: Rollback Test**: Ensure the rollback (downward migration) works without errors.

---

## 2. Tooling Details
- **Migration CLI**: `uv run alembic upgrade head`
- **Migration Smoke Test**: `env DATABASE_URL=sqlite+pysqlite:////private/tmp/pfs_alembic_smoke.db uv run alembic upgrade head`
- **Engine / ORM**: SQLAlchemy models with Alembic migrations; local runtime uses PostgreSQL via Docker Compose.
