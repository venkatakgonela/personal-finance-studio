# Skill: UI Change

---

## 1. Design & Layout Rules

When modifying user interfaces:

- **Rule 1: Responsive design**: Verify layout on mobile, tablet, and desktop breakpoints.
- **Rule 2: Styling standards**: Do not use ad-hoc colors or inline styles. Use pre-defined design tokens/variables.
- **Rule 3: Accessibility**: Ensure screen-reader compatibility (e.g. ARIA labels) and proper contrast ratios.
- **Rule 4: Verification**: Test interaction, forms, validation, and errors before code check-in.

---

## 2. UI Components Stack
- **Framework**: React + Vite + TypeScript with hand-authored CSS tokens in `frontend/src/styles.css`.
- **Local Dev Server**: `cd frontend && npm run dev`
- **Build Check**: `cd frontend && npm run build`
- **UI Test Gates**: `cd frontend && npm run test` and `cd frontend && npm run test:e2e`
