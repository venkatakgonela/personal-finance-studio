# Skill: Feature Development

---

## 1. Workflow Instructions

Follow this standard checklist when developing a new feature:

- **Step 1: Check specifications**: Read the corresponding [SPEC](file:///ai/specs/SPEC-000-template.md).
- **Step 2: Setup tests**: Create failing test cases first (TDD) if appropriate.
- **Step 3: Implement logic**: Write clean, modular code conforming to project style rules.
- **Step 4: Verify compatibility**: Ensure changes do not break existing components.
- **Step 5: Run quality gate**: Ensure linters, formatters, and type checks pass.

---

## 2. Project Verification Tools
- **Backend Tests**: `uv run pytest`
- **Backend Linter**: `uv run ruff check .`
- **Frontend Linter**: `cd frontend && npm run lint`
- **Frontend Tests**: `cd frontend && npm run test`
- **Frontend Build**: `cd frontend && npm run build`
- **Browser E2E**: `cd frontend && npm run test:e2e`
